How it works

The agent asks, Threefold decides, you see everything

Deterministic code decides every verdict. Amazon Bedrock only explains one in a sentence, and every answer says which of the two you are reading.

  1. Step one

    The hook asks

    Before the agent writes a file or runs a command, a small hook sends that tool call to Threefold. The same hook serves Claude Code, Codex and Antigravity, and a credential is refused on the machine and never sent.

  2. Step two

    Threefold judges, on AWS

    Gates written as plain code decide: a credential in the arguments, a domain file importing infrastructure, the same call repeating, a spend ceiling. A refusal comes back with its reason and a fix the same gates have checked.

  3. Step three

    The dashboard shows

    Every verdict lands in a ledger. The dashboard shows what was stopped, what would have been, and which rules have earned the right to refuse.

Two stages, so nothing breaks

Every project starts by watching. A rule refuses only after you have seen what it would have stopped and promoted it, and one click takes it back.

  1. Observe

    Every call is judged and recorded, and the service refuses none of them yet. What a rule would have stopped is kept for review.

  2. Review

    You mark each would-refuse correct or a false alarm. A rule whose every flag was correct reads Ready.

  3. Enforce

    Promote the ready rules and they refuse. The rules you leave out keep observing.

Demote is one click back to Observe, whenever a rule misbehaves.
