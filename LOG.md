The docstring claimed the old version "cannot be made to backtrack".
  - **Hostile content.** A 1 MB Python literal peaked at 747 MB inside `ast.parse` on a 256 MB function, deep nesting raised `RecursionError` (a 500), and 60 KB of unclosed `/*` took 7 s.   - **Explain judged paths the gate never would**, answering REFUSE for writes the gate approves. It now applies the gate's own path test and answers 400.
  - **A rule save was not all or nothing.** A mode typo was dropped with 200, a list sent as a string became one-character globs including `*`, a number was a 500, and a forty-first pattern was silently truncated. A save is now refused whole, and the 400 names each rule and the reason. `mode` is enforce only when missing or null. A duplicate id is refused because a refusal must name one rule. A draft with an unusable rule is not tried.

  - **A MultiEdit was judged on the text it removes.** Its edits carry no path of their own, so a fallback paired every string with the file, including `old_string`: deleting a forbidden import was refused for containing it. Content with no path now belongs to the nearest path above it, and removed text is never judged. This was a false refusal in enforce mode as well.
  - **Counting.** One rule watching two files of one call counted twice, and the ledger's target could name a different, clean file from the one observed. Both are fixed.
  - **Stored XSS.** Every page's `escapeHtml` returned a non-string as `String(value)` without escaping it, so a `tool_name` sent as a list reached the console as markup. Fixed on all six pages, and the ledger now stores identity fields as strings.
